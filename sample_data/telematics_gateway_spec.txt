## 1. System Overview

The Connected Sedan 2025 features a centralized E/E architecture with a
Telematics Gateway serving as the primary connectivity hub. The vehicle
integrates Cellular (4G/5G), Wi-Fi, Bluetooth LE, and GNSS interfaces
through a single Telematics Control Unit (TCU) manufactured by Continental.

## 5. External Interfaces

- **Cellular Modem**: Qualcomm SDX65 5G modem, firmware version 3.2.1
- **Wi-Fi**: 802.11ax (Wi-Fi 6), used for in-cabin hotspot and service downloads
- **Bluetooth LE 5.3**: Phone-as-key, tire pressure monitoring relay
- **OBD-II Port**: ISO 15765-4 (CAN), accessible under dashboard
- **USB-C**: Infotainment media and Apple CarPlay / Android Auto
- **GNSS**: u-blox NEO-M9N, used for navigation and fleet tracking

## 6. Security Controls (Current)

- TLS 1.3 mutual authentication between Cloud and TCU
- Secure Boot on TCU (vendor proprietary, not hardware-anchored)
- No SecOC on CAN FD powertrain segment
- No authentication on OBD-II diagnostic interface
- Basic IP firewall between Infotainment and ADAS domains
- OTA updates delivered via HTTPS but firmware signature verification is software-only
